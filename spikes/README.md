# Spikes

Small, throwaway test programs for Phase 1. Each one answers a technical question from `docs/PRD.md` (U1 to U7, S1) before we build the real feature.

Rules:

- Spikes are not part of the product. Product code under `src/` must never reference anything in this folder.
- Spikes are not in `WinIsland.slnx`, so CI does not build them and they cost no Actions minutes.
- Results go in `docs/spike-results.md`.
- Spikes can be deleted once their results are recorded and the real feature exists.
